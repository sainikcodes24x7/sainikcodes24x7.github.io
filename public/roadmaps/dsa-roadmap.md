# Data Structures and Algorithms Roadmap

## Phase 1 — Programming foundations

- Pick one language: C++, Java, Python, or C#.
- Learn variables, loops, functions, recursion, classes, and standard collections.
- Understand time and space complexity, Big-O, Big-Theta, and amortized analysis.
- Practice tracing code by hand before optimizing it.

## Phase 2 — Core data structures

- Arrays and strings: traversal, prefix sums, difference arrays, and matrices.
- Linked lists: reversal, fast/slow pointers, and cycle detection.
- Stacks and queues: monotonic stacks, deques, and expression evaluation.
- Hash maps and sets: counting, grouping, lookup, and collision concepts.
- Trees: traversals, binary search trees, heaps, and tries.
- Graphs: adjacency lists, adjacency matrices, directed and weighted graphs.

## Phase 3 — Problem-solving patterns

- Two pointers and sliding windows.
- Binary search on values and answers.
- Recursion, backtracking, subsets, permutations, and combinations.
- Greedy algorithms and interval problems.
- Divide and conquer.
- Dynamic programming: 1D, 2D, subsequences, knapsack, and state compression.

## Phase 4 — Graph algorithms

- Breadth-first and depth-first search.
- Topological sorting and cycle detection.
- Union-Find / Disjoint Set Union.
- Dijkstra, Bellman-Ford, and Floyd-Warshall.
- Minimum spanning trees using Prim and Kruskal.
- Strongly connected components and bridges.

## Phase 5 — Interview preparation

- Solve problems by topic first, then mixed sets.
- Write the brute-force approach before optimizing.
- Explain complexity and edge cases aloud.
- Complete timed mock interviews and review failed problems.
- Maintain a revision list of reusable patterns.

## Suggested 12-week schedule

1. Weeks 1–2: complexity, arrays, strings, hashing.
2. Weeks 3–4: linked lists, stacks, queues, binary search.
3. Weeks 5–6: trees, heaps, tries, recursion.
4. Weeks 7–8: graphs and greedy algorithms.
5. Weeks 9–10: dynamic programming.
6. Weeks 11–12: mixed practice and mock interviews.

## Completion project

Build a searchable algorithm notebook containing the problem statement, approach, complexity, implementation, and mistakes learned for every solved problem.
